FÁCILPRO 4.1 — SINCRONIZAÇÃO NA NUVEM

O QUE MUDA
- Cadastro e login continuam usando o Supabase.
- Clientes, serviços, agenda e despesas passam a sincronizar com uma tabela por usuário.
- Cada conta só pode consultar seus próprios dados: RLS + uma função de gravação por revisão.
- Mantemos um backup local neste navegador, com aviso se a internet falhar.
- Em caso de alterações diferentes em dois dispositivos, o app pede que você escolha uma cópia.

INSTALAÇÃO (SIGA NA ORDEM)
1. ANTES DE ATUALIZAR: no FácilPro 4.0, faça login e abra Financeiro > Exportar backup JSON.
   Guarde o arquivo baixado. Não apague dados antigos nem desinstale o app.
2. No projeto Supabase 'facilpro-4', abra SQL Editor > New query.
   Abra o arquivo CONFIGURAR-SUPABASE-FACILPRO-4.1.sql (enviado separadamente),
   copie TODO o texto, cole no editor e execute em Run.
   A execução cria a tabela com RLS e uma função protegida de gravação.
3. Depois que o SQL terminar sem erros, envie os 8 arquivos de site da pasta
   FácilPro-4.1-nuvem para a RAIZ do repositório GitHub 'facilpro':
   index.html, config.js, cloud.js, sw.js, manifest.webmanifest,
   icon-192.png, icon-512.png e (opcional) este LEIA-ME.txt.
   Confirme as alterações no branch main; não envie o ZIP fechado.
4. Abra https://lucas01lab.github.io/facilpro/ no Chrome e atualize com Ctrl+Shift+R.
5. Faça login. Espere aparecer "Sincronizado com a nuvem" ou "Dados carregados da nuvem".
   Os dados existentes desse navegador são importados automaticamente se a nuvem estiver vazia.
   Se o app mostrar um aviso de conflito, escolha com cuidado, usando seu backup para conferir.
6. Teste em OUTRO dispositivo usando a mesma conta. Confira se clientes e serviços aparecem.

O QUE FAZER EM CASO DE ERRO
- "Banco ainda não configurado": confira se executou o arquivo SQL no projeto correto.
- "Sem conexão": alterações podem continuar sendo feitas localmente. Toque em
  "Sincronizar novamente" quando a internet voltar.
- "Dados diferentes": exporte o backup JSON antes de decidir qual cópia prevalece.
- "Limite 1 MB": exporte um backup e revise a quantidade de registros.

LIMITAÇÕES DESTA PRIMEIRA VERSÃO
- Os dados locais no navegador não são criptografados.
- Sincronização por documento inteiro de cada usuário, sem edição colaborativa em tempo real.
- Proteção contra sobrescritas por versão, mas conflitos exigem escolha manual.
- Exige internet para autenticação e sincronização. Trabalho offline fica só no aparelho
  até conseguir conectar, sem promessa de sincronização enquanto offline.
- Não há servidor próprio de backups automáticos. Faça backups JSON regularmente.

SEGURANÇA
- config.js contém APENAS a chave pública do Supabase.
- Nunca publique uma senha de banco, chave secret ou service_role no GitHub.
- Não copie o arquivo .sql para substituir o index.html.
